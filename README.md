# Staysafe — Cybercrime Awareness

Vite + React + TypeScript port of the Staysafe site. Markup, copy, styles and behaviour are unchanged from the original HTML/CSS/JS version.

```bash
npm install
npm run dev      # local dev server
npm run build    # production build in dist/
```

## Structure

```
src/
  App.tsx              page state, mobile menu state
  index.css            original style.css, unchanged
  components/          Header, Footer, Terminal (live incident feed)
  pages/               Home, Learn, Spot, Report
```
